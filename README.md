# README.md

## Project Overview

This iOS Process Control Management project aims to simulate and analyze how process control, process scheduling, and process synchronization work in operating systems that resemble iOS in certain aspects. In other words, the task is to demonstrate how multiple processes can be executed by CPU and which process scheduling algorithms, synchronization methods and process states should be used to do so. Thus, the primary purpose of the project is to implement and analyze CPU process execution, scheduling methods, and resource management techniques. 

## Project Workflow and Contents
The process control project workflow starts from the process definition stage during which processes will require some basic parameters: arrival time, burst time, priority level, or any other information needed to implement process states. After that, different process management or scheduling algorithms will be utilized to show how CPU works. In particular, the project can demonstrate the process creation, process execution, process waiting time, and process turnaround time calculations. The process control notebook implementation can include algorithms such as FCFS, Round Robin, Priority Scheduling, or multistage processes. The use of Jupyter Notebook for implementation allows combining theoretical and practical parts in one document.
